# 🛍️ Vrinda Store – Quantitative Sales & BI Analytics Dashboard

## 📊 Project Overview

Vrinda Store Sales Analytics is an end-to-end Business Intelligence project designed to analyze retail sales performance, customer purchasing behavior, product trends, and marketplace dynamics.

The project processes and analyzes 31K+ orders representing INR 2.1Cr+ in transactions. The analysis combines data cleansing, quantitative analysis, KPI development, and interactive dashboarding to transform raw transactional data into actionable business insights.

---

## 🎯 Business Objective

The primary objective of this project is to:

- Analyze overall retail sales performance
- Identify monthly and seasonal sales trends
- Evaluate customer purchasing behavior
- Identify high-performing product categories
- Analyze marketplace/channel performance
- Track key business KPIs
- Identify patterns and opportunities for business growth
- Present insights through interactive BI dashboards

---

## ✨ Key Features

### 🧹 Data Cleaning & Preparation

- Cleaned and validated transactional records
- Handled missing and inconsistent values
- Standardized categorical fields
- Prepared data for quantitative analysis
- Validated key sales and order metrics

### 📈 Sales Performance Analysis

- Analyzed total sales and order volume
- Evaluated monthly sales trends
- Identified high-performing categories
- Compared sales performance across channels
- Analyzed marketplace dynamics

### 👥 Customer Analysis

- Evaluated customer purchasing patterns
- Analyzed order distribution
- Identified customer growth trends
- Studied category-level customer behavior

### 📊 KPI Dashboard

The interactive dashboard provides visibility into:

- Total Sales
- Total Orders
- Average Order Value
- Category Performance
- Sales Trends
- Channel/Marketplace Performance
- Customer Trends
